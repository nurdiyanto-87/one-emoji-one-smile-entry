**One Emoji, One Smile** — a tiny pure-stdlib Python program that writes exactly one emoji to `/output/entry.txt`: 🌞, the sun with a face. A smiling face plus the sun itself: warmth at first glance, read the same way by a stranger of any age or background, a deliberate pick rather than the first default smiley, and safe from a stranger — no intimacy, sarcasm or flirtation. One character, nothing else in the file.

## Run it

```sh
python3 main.py
# writes exactly one emoji to /output/entry.txt
```
